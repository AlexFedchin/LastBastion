# Repo notes

- Use Claude Artifact as a primary way to communnicate the changes.
  - For every visual change make an artifact page with screenshots showing before/after change.
  - Visual changes should be shown by the one pictures with a before/after slider. The pictures should be openable full screen.
  - Do not include the audio files or lines.
  - Put a short summary of the changes in the top of the page.
- After every change commit and push to main without asking.
- If user asks to plan something to do later - put it into a suitable .md file or create a new one and commit to the repo.
- All the new textures that need to be added should be downloaded from AmbientCG instead of generating them with code unless explicitly stated otherwise.
- All the new sounds have to be downloaded from FreeSound instead of synthesizing them in code.
