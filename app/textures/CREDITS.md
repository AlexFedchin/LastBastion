# Last Bastion: texture credits

Surface textures are CC0 scans from [Poly Haven](https://polyhaven.com), converted by
`scripts/textures/build_textures.py`:
- brightness matched to the procedural textures they replace
- tinted surfaces partly desaturated
- ambient occlusion baked into the colour
- shipped as WebP at 2048, 1024 and 512 px

The game falls back to its procedural textures if a file is missing.
